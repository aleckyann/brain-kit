# Second brain

The front door of this vault. An agent reads this page first and follows links from here, one note at a time, instead of loading everything.

## Areas

- [Core](core/index.md): who the owner is, what they value, how the agent answers, how decisions are made, and the weekly rhythm.
- [People](people/index.md): one note per person. Confidential: see [SECURITY.md](SECURITY.md).
- [Organizations](organizations/index.md): one note per company, client, partner or institution.
- [Projects](projects/index.md): one note per project, with its stage.
- [Decisions](decisions/index.md): one note per decision worth remembering, and why it was made.
- [Reflections](reflections/index.md): dated thinking that is not yet a decision.
- [References](references/index.md): what the owner reads and learns from.
- [Pending](pending/index.md): follow-ups with a deadline and promises made to people.
- [Memory](memory/index.md): the log where every new fact is captured before it is compiled into a note.
- [Attachments](attachments/index.md): files that notes point to.
- [Templates](templates/index.md): one template per collection, copied when a new note is created.

## How this vault works

- [AGENTS.md](AGENTS.md): the contract every agent working here follows.
- [CLAUDE.md](CLAUDE.md): the pointer Claude Code reads first.
- [CONVENTIONS.md](CONVENTIONS.md): file names, frontmatter, links and tables.
- [SECURITY.md](SECURITY.md): third-party data, removal on request, and what to do if a secret gets in.
